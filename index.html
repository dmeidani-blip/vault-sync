DSARM Vault Sync

DSARM Vault Sync is a private, single-user configuration of the open-source Obsidian plugin Google Drive Vault Sync. It synchronises one personal Obsidian note vault between the owner's own devices using the owner's own Google Drive account.

What it does

  • Uploads note files from a local Obsidian vault to a dedicated folder in the owner's Google Drive.
  • Downloads changes made on other devices belonging to the same owner.
  • Keeps a manifest file so it can tell which files changed between runs.

Access requested

The application requests only the https://www.googleapis.com/auth/drive.file scope, which limits it to files and folders it creates itself. It cannot see or read any other content in the Google Drive account.

Who it is for

This application is not offered to the public. It has one user, the account owner, and exists solely to synchronise that person's own notes between their own devices.
